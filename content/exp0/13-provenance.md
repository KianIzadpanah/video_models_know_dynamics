## Manifests

Each pipeline stage writes a manifest with one entry per clip. Together they give
full provenance for all 81 clips.

| file | stage | entries | what it records |
|---|---|---|---|
| `configs/prompts.json` | input | 9 | prompt text, pair, load, tier, seed frame index |
| `data/motions/manifest.json` | T2M | 27 | model, checkpoint, seed, generated length, trim, fit residual, ground offset |
| `data/renders/manifest.json` | render | 27 | camera pose and FOV, resolution, shadow samples, source motion path |
| `data/videos/manifest.json` | T2V + I2V | 54 | model, repo, exact prompt used, conditioning-image hash, cache key, generation seconds |
| `results/montage/manifest.json` | montage | 39 | which composed file exists per seed |

## Generation cost

::: metrics src=data/videos/manifest.json cols=prompt_id:prompt,source:arm,seed:seed,gen_seconds:seconds,frame_hash:cond. image hash sort=-gen_seconds limit=12
The twelve slowest video generations. `frame_hash` is a hash of the conditioning
image, so an I2V entry can be tied back to the exact still it was seeded on;
`cache_key` in the same manifest identifies a reusable generation.
:::

## Reproducing the run

The pipeline is stage-by-stage and each stage is idempotent — a stage skips any
clip whose manifest entry already matches its inputs. Re-running from scratch
requires the MotionGPT3 checkpoint and the SMPL body models, neither of which is
redistributable; both are referenced by path in `configs/`.

::: note title="The clips on this site are transcodes"
Everything shown in these pages is a web-sized H.264 copy — capped at 720 px wide,
CRF 28, no audio, `faststart` — generated by the site's `build.py`. The
full-resolution originals are the files listed above and were not modified. Frame
counts, timings and playback rates are unchanged by the transcode; only spatial
resolution and bitrate are.
:::

## The original contact sheet

`results/sheet.html` is the standalone single-page contact sheet written during
the run, before this site existed. It reads the same clips directly from
`data/` and remains the fastest way to see all 81 at full resolution on one page.
